# Служебные инструменты

Запускать только вручную в согласованном серверном окружении. Основной сервис — `python -m src.main`, Dokploy запускает его автоматически.

- `python -m src.tools.login` — однократная авторизация аккаунта Telethon. Инструмент выводит секретную SESSION: передайте её в env, не публикуйте в логах/репозитории.
- `python -m src.tools.backfill --days 30` — скачать историю доступных источников **только в архив SQLite**. Не вызывает Jev, не создаёт лиды и не рассылает историю. Не запускайте второй MTProto-клиент параллельно production с той же файловой сессией; используйте отдельное согласованное окно обслуживания.

Чаты добавляются через бота ссылками или @именами и хранятся в БД. Редактирование YAML для чатов и старые генераторы больше не используются.

Регрессионные тесты находятся в `tests/`; `python -m pytest -p no:cacheprovider -q tests`. По указанию владельца тесты выполняются на сервере, изолированно от production-БД, сети и секретов. Сохранённые ответы Jev позволяют проверять композицию без расходов на API.
