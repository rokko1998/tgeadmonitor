При деплое аккаунт мониторинга проверит эти адреса и при необходимости вступит в чаты последовательно через сохраняемую очередь. Доступность, фактическое название и тип сущности проверяются Telegram API на сервере. Пока вступление не подтверждено, источник не считается активным. Повторяющиеся адреса объединяются без учёта регистра; известный числовой chat_id сохраняется.

Существующие `config/chats.yaml` и `config/professional_chats.yaml` сохранены. Для чатов из документа включён `auto_join`; прочие старые источники автоматически не вступают в новые группы. География не ограничивает уведомления ни для одной категории источников.

## Вход через другого бота

`@RostovRabota_Bot` и `@ClubBuildersDesignersBot` — посредники для доступа, а не адреса чатов. Они не включены в мониторинг. Нужно самостоятельно пройти анкету/получить доступ, затем отправить нашему боту прямую ссылку на целевой чат или приглашение. Автоматическая переписка с этими ботами не выполняется.
